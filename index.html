Git Interactive Learning Guide

Your quick-reference cheat sheet for mastering version control.

1. What is Git?

Git is a Distributed Version Control System (DVCS). It tracks changes in your source code during software development, allowing multiple developers to work together smoothly without overwriting each other's work.

2. Initial Setup

Before making your first commit, configure your identity so Git knows who authored the changes.

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

3. Starting a Repository

Initialize a brand new local repository, or clone an existing project from a remote server like GitHub.

git init

Creates a hidden .git directory in your current project folder.

git clone <repository-url>

Downloads an existing project to your computer.

4. The Basic Workflow

Git projects have three main areas: the Working Directory, the Staging Area, and the Git Repository.

Step A: Check project status

git status

Step B: Stage your changes

git add index.html

Or use git add . to stage all modified files at once.

Step C: Commit your changes

git commit -m "Add core learning layout"

5. Branching & Merging

Branches let you isolate your work to build new features safely without breaking the main project code.

git branch <branch-name>

Creates a new branch.

git checkout <branch-name>

Switches your working files to that branch.

git merge <branch-name>

Combines the specified branch's history into your current active branch.

Pro Tip: Always run git pull before starting a new feature branch to ensure your local history matches your remote team's latest updates.
